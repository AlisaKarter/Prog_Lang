* **Тип в программировании** - множество допустимых значений и операций, которые можно выполнять над этими значениями. Тип определяет, как интерпретируются биты в памяти и какие операции применимы к данным.
* **Типизация** — система правил и ограничений, определяющих, как типы данных взаимодействуют друг с другом в программе, включая правила присваивания, передачи параметров и выполнения операций.
* **Статическая типизация** - система типизации, при которой типы переменных определяются на этапе компиляции (трансляции). Ошибки несоответствия типов обнаруживаются до запуска программы. Пример: C++, Java.
* **Динамическая типизация** - система типизации, при которой типы переменных определяются во время выполнения программы. Переменная может хранить значения разных типов в разные моменты времени. Пример: Python, JavaScript.
* **Неявная типизация** - система, при которой тип переменной определяется автоматически на основе присвоенного значения, без явного указания типа в объявлении. Пример: auto x = 5; в C++ или x = 5 в Python.
* **Явное преобразование типа** - операция приведения одного типа данных к другому, явно указанная программистом в коде. Пример: static_cast<int>(3.14) в C++ или int("5") в Python.
* **Неявное преобразование типа** - автоматическое приведение одного типа данных к другому, выполняемое компилятором или интерпретатором без явного указания программиста. Пример: преобразование int к double при арифметических операциях в C++.
* **Сильная типизация** - система типизации, при которой язык не позволяет смешивать разные типы данных без явного преобразования. Операции между несовместимыми типами вызывают ошибку. Пример: Python (нельзя сложить строку и число без явного преобразования).
* **Слабая типизация** - система типизации, при которой язык автоматически выполняет преобразования между типами данных, даже если они несовместимы. Пример: JavaScript ("5" + 3 даст "53", а не ошибку).
* **Преобразование типов** — процесс изменения значения переменной одного типа в значение другого типа. Может быть явным (указанным программистом) или неявным (выполняемым автоматически).
* **Правило одного определения (ODR)** — правило в C++, требующее, чтобы каждый объект имел не более одного определения в своей области видимости.

### Задание 2 **(3)**
*Запишите правила неявного преобразования типов в языке С++*

**Преобразования при присваивании**  
При присваивании значение правой части автоматически приводится к типу левой части.
Основные правила:
* Если типы разной длины, то преобразуется меньший к большему
* Если типы равной длины и один знаковый, а другой беззнаковый — знаковый приводится к беззнаковому
* Если один целый, а другой вещественный — целый приводится к вещественному  
Пример:
```c++
short a = 20000, b = 30000;
short c = a + b;
cout << c << ' ' << a + b;
```
**Преобразования при арифметических действиях**  
При выполнении бинарных арифметических операций операнды приводятся к общему типу по правилам:
* Разная длина типов - меньший приводится к большему
* Равная длина, разная знаковость - знаковый приводится к беззнаковому
* Целый и вещественный - целый приводится к вещественному  
Пример:
```c++
int x = -4;
unsigned y = 2;
cout << x / y;
```
**Преобразования с логическими значениями**  
Тип bool неявно преобразуется в целочисленный тип при участии в арифметических операциях:
* false - 0
* true - 1  
Целочисленные и другие типы преобразуются к bool в логических выражениях:
* 0 - false
* ненулевое значение - true  
Примеры:
```c++
cout << 'a' + true << endl;
```
Результат: 98  
Пояснение: Символ 'a' имеет код 97. Значение true неявно преобразуется к 1. Результат: 97 + 1 = 98.
```c++
cout << (3 < 2 < 1);
```
Результат: 1 (true)

### Задание 4 **(1)**

*Рассмотрите следующий фрагмент программы.*

```c++
bool x = true, y = false;
auto a = x & y;
std::cout << typeid(a).name() << std::endl;
auto b = x && y;
std::cout << typeid(b).name() << std::endl;
```
*Используя* **typeid**, *найдите типы переменных* **a** и **b**. *Объясните результат.*
<img width="503" height="122" alt="image" src="https://github.com/user-attachments/assets/b0f17ef9-c922-4126-8dfd-0be9c8abc585" />  
Получаем: a = x & y - int, b = x && y - bool    
#### Пояснение:  
**Переменная a:** оператор & (побитовое И)  
1.Сначала компьютер переводит числа в двоичный код  
2.Затем он «накладывает» их друг на друга и применяет правило оператора &  
3.В итоге мы получаем число  
Результат побитовой операции над двумя int имеет тип int. Поэтому auto a = x & y; выводит тип a как int.  
**Переменная b:** оператор && (логическое И)  
Поэтому auto b = x && y; выводит тип b как bool.

### Задание 5. **(2)**

*Приведите разумные (логичные) примеры использования в 
С++ ключевых слов* **typedef, auto, decltype, static_cast** и оператора **sizeof**.

**Файл: typedef_exmpl.cpp**  
```c++
#include <iostream>
#include <vector>

typedef std::vector<int> IntVector;
typedef long long LL;

int main() {
    IntVector numbers = {1, 2, 3, 4, 5};
    LL number = 1000000000;
    
    std::cout << "Vector size: " << numbers.size() << std::endl;
    std::cout << "Number: " << number << std::endl;
}
```
Пояснение:  
typedef позволяет создать короткое имя для сложного типа. В примере:  
IntVector - псевдоним для std::vector<int>, что упрощает объявление векторов  
LL - псевдоним для long long

**Файл: auto_exmpl.cpp**  
```c++
#include <iostream>

int main() {
    auto x = 42;
    auto y = 3.14;
    auto z = true;
    std::cout << x << " " << y << " " << z << std::endl;
}
```
Пояснение: auto позволяет компилятору автоматически определить тип переменной по значению инициализатора. x будет int, y — double, z — bool.  

**Файл: decltype_exmpl.cpp**  
```c++
#include <iostream>

int main() {
    int x = 10;
    double y = 3.14;
    decltype(x) a = 20;
    decltype(y) b = 2.71;
    std::cout << a << " " << b << std::endl;
}
```
Пояснение: decltype(выражение) определяет тип переменной по типу другого выражения. a имеет тип int (как x), b имеет тип double (как y). 

**Файл: static_cast_exmpl.cpp**  
```c++
#include <iostream>

int main() {
    double pi = 3.14159;
    int x = static_cast<int>(pi);
    std::cout << pi << " " << x << std::endl;
    
    int a = 5, b = 2;
    double result = static_cast<double>(a) / b;
    std::cout << result << std::endl;
}
```
Пояснение: static_cast выполняет явное преобразование типа. В первом случае double преобразуется в int (отбрасывается дробная часть). Во втором случае int преобразуется в double, чтобы деление было вещественным (результат 2.5, а не 2).

**Файл: sizeof_exmpl.cpp**  
```c++
#include <iostream>

int main() {
    std::cout << "char: " << sizeof(char) << std::endl;
    std::cout << "int: " << sizeof(int) << std::endl;
    std::cout << "double: " << sizeof(double) << std::endl;
    
    int x = 42;
    std::cout << "x: " << sizeof(x) << std::endl;
}
```
Пояснение: sizeof возвращает размер типа или переменной в байтах. Обычно char — 1 байт, int — 4 байта, double — 8 байт.
