#### Квадратные скобки [] являются оператором индексации. Они используются для доступа к элементу массива или контейнера по индексу. Пример: arr[0] = 5;
#### Не как оператор (синтаксическая конструкция): При объявлении массива скобки являются частью спецификатора типа и указывают размерность, а не выполняют операцию над операндами во время выполнения. Пример: int arr[10];
#### Круглые скобки () Как оператор: Оператор вызова функции. Используется для передачи управления функции и аргументам. Пример: printf("Hello"); Оператор приведения типа. Явное преобразование типа. Пример: int x = (int)3.14;
#### Не как оператор (синтаксическая конструкция): Группировка выражений. Изменение приоритета операций. Пример: int c = (a + b) * 2; (Скобки здесь не "выполняются", они лишь задают порядок вычислений для других операторов). Список параметров при объявлении функции. Пример: void myFunc(int a, int b);
## Задание 5
### 1. Лексический анализ токенов
| Тип токена | Элементы кода | Примечание |
| :--- | :--- | :--- |
| **Ключевые слова** | `for`, `in` | Зарезервированные идентификаторы синтаксиса. |
| **Идентификаторы** | `print`, `map`, `sum`, `zip`, `int`, `input`, `split`, `i` | Имена функций, методов и переменных. |
| **Литералы** | `(1, 2, 3)` | Кортеж из трех целочисленных литералов. |
| **Операторы / Пунктуаторы** | `*`, `.`, `(`, `)`, `[`, `]`, `,` | Распаковка (`*`), доступ к атрибутам (`.`), вызов/группировка, список, разделитель. |
#### Скобки после имен функций являются оператором вызова. Символ `*` перед `map(...)` — унарный оператор распаковки итератора.
### 2. Классификация идентификаторов
| Идентификатор | Роль | Пояснение |
| :--- | :--- | :--- |
| `i` | **Переменная** | Управляющая переменная цикла `for`. Локальна в генераторе списка. |
| `print`, `map`, `sum`, `zip`, `int`, `input` | Функция | Встроенные функции языка. |
| `split` | **Метод** | Метод класса `str`, вызываемый через оператор `.`. |
### 3. Вызываемые функции и параметры
#### Вызовы выполняются от внутренних к внешним:
1.  `input()`: без параметров. Читает строку.
2.  `str.split()`: вызывается на результате `input()`. Без параметров (разделение по пробелам). Возвращает список строк.
3.  `int(x)`: параметр — строка из `split`. Преобразует в целое число.
4.  `map(int, iterable)`: параметры — функция `int` и результат `split`. Возвращает итератор чисел.
5.  Генератор списка `[... for i in (1,2,3)]`: создает список из 3 итераторов. `input()` вызывается **3 раза**.
6.  `*list_expr`: распаковывает список из 3 итераторов в отдельные аргументы.
7.  `zip(iter1, iter2, iter3)`: принимает 3 итератора. Группирует элементы по позициям (транспонирование).
8.  `sum(iterable)`: принимает кортеж от `zip`. Возвращает сумму его элементов.
9.  `map(sum, zip_result)`: применяет `sum` к каждому кортежу.
10. `print(*iterable)`: распаковывает результаты внешней `map` и выводит их через пробел.
### 4. Семантический анализ: что делает программа
#### Программа читает три строки с целыми числами и вычисляет их поэлементную сумму, выводя результат в одну строку.
#### Пошаговое выполнение:
1.  **Чтение данных:** Генератор списка выполняется 3 раза (по элементам кортежа `(1,2,3)`). На каждой итерации считывается строка, разбивается на числа и преобразуется в итератор `int`.
    *   Пример ввода: `1 2 3`, `4 5 6`, `7 8 9`.
2.  **Транспонирование:** Оператор `*` передает три итератора в `zip`. Функция группирует элементы по индексам: `(1,4,7)`, `(2,5,8)`, `(3,6,9)`.
3.  **Суммирование:** Внешняя `map(sum, ...)` применяет суммирование к каждому кортежу:
    *   `sum((1,4,7))` → `12`
    *   `sum((2,5,8))` → `15`
    *   `sum((3,6,9))` → `18`
4.  **Вывод:** Оператор `*` в `print` распаковывает полученные суммы. Результат: `12 15 18`.
#### Поскольку `map(int, input().split())` находится внутри генератора списка, функция `input()` вызывается трижды. Программа ожидает ввод трех отдельных строк, а не одной строки со всеми данными.
## Задание 6
### В языке C++ существуют два способа записи комментариев:
1. Однострочные комментарии — начинаются с // и заканчиваются концом строки
2. Многострочные комментарии — начинаются с /* и заканчиваются */
### Пример 1: синтаксически верный(но это не комментарий)
```cpp
cout<<"Hello /* Это комментарий */ world";
```
Почему верный: Символы /* и */ находятся в кавычках. Токенизатор воспринимает их как обычные символы строки, а не как начало/конец комментария.
При выполнении программы на экран будет выведено: Hello /* Это комментарий */ world
### Пример 2: синтаксически верный
```cpp
// /* Это комментарий */
```
Почему верный: Символы // начинают односторочный комментарий, поэтому всё, что следует после них до конца строки (включая /* Это комментарий */), игнорируется транслятором.
Последовательность /* */ внутри односторочного комментария не имеет специального значения.
### Пример 3: синтаксически неверный
```cpp
/* Я комментирую программы /* комментарий */ */
```
Почему неверный: В C++ многострочные комментарии не поддерживают вложенность. Токенизатор работает следующим образом:
Первый /* начинает комментарий
Первый встреченный */ (после слова "комментарий") закрывает комментарий
Последний */ остаётся без открывающей пары, что вызывает синтаксическую ошибку
Результат: Ошибка компиляции error: expected unqualified-id before '/' token или аналогичная.
### Пример 4: синтаксически верный
```cpp
// Я комментирую программы /* комментарий */
```
Почему верный: Символы // начинают односторочный комментарий, поэтому вся строка до её конца игнорируется. Последовательность /* комментарий */ является просто текстом внутри односторочного комментария и не обрабатывается как начало/конец многострочного комментария.
### Пример 5: синтаксически верный
```cpp
/* Я комментирую свои программы
// Это комментарий до конца строки
*/
```
Почему верный: Символы /* начинают многострочный комментарий, который продолжается до первого встреченного */. Внутри многострочного комментария последовательность // не имеет специального значения — это просто два символа слэша. Весь текст между /* и */ (включая строку с //) игнорируется транслятором.
## Задание 7
### 1. Цикл while
Первый вид — цикл while, который соответствует строке правила:
while ( condition ) statement
Формат записи (по правилу): ключевое слово while, в круглых скобках условие condition, далее инструкция statement.
Пример фрагмента программы:
```cpp
int x = 1;
while (x < 1000) {
    cout << x;
    x *= 2;
}
```
### 2. Цикл do-while
Второй вид — цикл do-while, который соответствует строке правила:
do statement while ( expression );
Формат записи (по правилу): ключевое слово do, затем инструкция тела цикла statement, далее ключевое слово while, в круглых скобках выражение условия expression, завершается точкой с запятой.
Пример фрагмента программы:
```cpp
int n = 5;
do {
    cout << n << " ";
    --n;
} while (n > 0);
```
### 3. Классический цикл for
Третий вид — классический цикл for, который соответствует строке правила:
for ( init-statement conditionopt ; expressionopt ) statement
Формат записи (по правилу): ключевое слово for, в круглых скобках через точку с запятой разделяются: инициализирующая инструкция init-statement, необязательное условие condition (суффикс opt означает optional) и необязательное выражение инкремента/изменения expression, далее инструкция тела цикла statement.
Пример фрагмента программы:
```cpp
for (int i = 0; i < 10; ++i) {
    cout << i << " ";
}
```
### 4. Цикл for по диапазону (range-based for)
Четвертый вид — цикл for по диапазону, который соответствует строке правила:
for ( for-range-declaration : for-range-initializer ) statement
Формат записи (по правилу): ключевое слово for, в круглых скобках объявление переменной для итерации for-range-declaration, затем двоеточие, затем инициализатор диапазона for-range-initializer, далее инструкция тела цикла statement.
Пример фрагмента программы:
```cpp
std::vector<int> v = {1, 2, 3};
for (auto& el : v) {
    cout << el * 2 << " ";
}
```
