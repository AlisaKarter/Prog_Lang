```
char a = 'a';

```

Вычисление: 97 + 10 = 107 (тип int)

Второе сложение:  
Вычисление: 107 + 250 = 357 (тип int)

Младшие 8 бит: 01100101 = 101 в десятичной системе  
По таблице ASCII код 101 соответствует символу 'e'.
Второй вывод: e  
Итог: ke

### Задание 4 **(2)**

*Перепишите программу из предыдущего задания на Python, используя функции* **chr** и **ord**.
*Почему ее вывод отличается от вывода программы на С++?*

```python
a = 'a'
a = chr(ord(a) + 10)
print(a, end='')
a = chr(ord(a) + 250)
print(a, end='')
```
ord('a') возвращает код символа 'a' в Unicode: 97  
97 + 10 = 107  
chr(107) возвращает символ с кодом 107: 'k'  
Первый вывод: k  
ord('k') возвращает код символа 'k': 107  
107 + 250 = 357  
chr(357) возвращает символ с кодом 357 в Unicode: 'ļ'  
Второй вывод: ļ

В C++ тип char занимает ровно 1 байт (256 возможных значений). Когда результат сложения 107 + 250 = 357 не помещается в этот диапазон, происходит усечение. Код 101 соответствует символу 'e'.  
В Python функция chr() работает с полным диапазоном Unicode (от 0 до 1 114 111), поэтому код 357 корректно преобразуется в соответствующий символ 'ļ' без какого-либо усечения.

### Задание 5. **(2)**

*Объясните работу фрагмента программы на С++. В частности, почему* $x+x-x=x$, *но при этом*
$(x\cdot 2)/2\neq x$? *В отчете надо привести вычисления, приводящие к ответу.*
```
unsigned short x = 40000;
unsigned short y = x + x;
unsigned short z = x * 2;
y = y - x;
z = z / 2;
std::cout << y << " " << z << std::endl;
```
Тип unsigned short занимает 2 байта (16 бит). Максимальное значение: 2^16 − 1 = 65535.  
**unsigned short y = x + x;**  
Срабатывает правило целочисленных продвижений: оба операнда unsigned short автоматически приводятся к int.  
Вычисление в int: 40000+40000=80000  
При присваивании unsigned short происходит усечение до 14464  
**unsigned short z = x * 2;**  
Аналогично, x приводится к int.
Вычисление в int: 40000 * 2 = 80000
Усечение: 14464  
**y = y - x;**  
Вычисление в int: 14464−40000=−25536  
При присваивании в unsigned short: −25536 mod 65536 = 40000  
y = 40000  
**z = z / 2;**  
Вычисление в int: 14464/2 = 7232
Помещается в unsigned short без усечения.
z = 7232

**Почему x + x - x = x, но (x * 2) / 2 ≠ x**  
short всегда заранее становится обычным int (сохраняя минус), а обычный int подстраивается под unsigned int и теряет знак.
